# Soujata Exim

Official website for Soujata Exim - Eco-Friendly Bags Manufacturer & Exporter from India.

## About

Soujata Exim is a trusted Indian manufacturer and exporter of sustainable, eco-friendly bags made from jute, cotton, and canvas. We specialize in custom packaging solutions for global brands.

## Tech Stack

- **Framework:** Next.js 16.2.3
- **Frontend:** React 19.2.4
- **Styling:** Tailwind CSS 4
- **Language:** TypeScript
- **Font:** Geist Sans & Geist Mono

## Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, or bun

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd soujata-exim
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
bun install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```

#### Organization Schema
- Defines company identity and branding
- Includes founding date, contact info, social profiles
- Helps with Knowledge Graph and brand searches

#### LocalBusiness Schema
- Defines business location and services
- Includes address, phone, email, service areas
- Helps with local search results and geographic targeting
- Covers export markets: USA, Germany, Malaysia, Dominican Republic, Spain, Mexico

### Technical SEO
- **Robots.txt:** Crawling instructions for search engines
- **Sitemap.xml:** Site structure for better indexing
- **Security Headers:** X-Frame-Options, X-Content-Type-Options, etc.
- **Performance:** Image optimization, Core Web Vitals optimization
